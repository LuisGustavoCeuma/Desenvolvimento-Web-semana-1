# Desenvolvimento Web – Semana 01

Blog em HTML com estrutura semântica e formulário de inscrição.

## Arquivo

- `atv 1 web.html`

## Conteúdo

- `<header>` com `<h1>` e nav com 3 links
- `<main>` com 2 `<article>` (Variáveis e Listas), cada um com `<h2>`, `<p>` e `<img>`
- `<aside>` com formulário `method="get"`: nome (mín. 3 letras), e-mail, idade (18 a 120), `<select>` com 3 assuntos e checkbox de termos
